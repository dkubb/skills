# Recon discipline — before any design or build

1. **API-recon before build.** A mechanism named in a spec/plan is a CLAIM;
   verify it exists at the stated location and shape before designing
   against it. Recon-finds-the-machinery-already-exists reshapes the
   agenda: the rung's real content is often "instantiate the EXISTING
   pattern at the real type", not "build the pattern".
2. **Arc-reshaping recon.** When a rung nominally targets a COMPOSITION
   (admit→lower), recon the TYPE GAP first: if the two carriers share no
   bridge and the missing data is unrecoverable from one side, the
   composition is a separate later rung needing a shared authored source
   with two projections — not a total `carrier → record` map. A recon that
   finds the mirage fires the design gate with a negative finding; that is
   a success, not wasted work.
3. **Design-round-skip criterion.** Skip a design round ONLY when every
   degree of freedom is determined by already-reviewed pieces — a straight
   sibling composed of already-reviewed semantics with no new
   correspondence CLAIM needs no design round; the code round adjudicates.
   A recon that refutes a roadmap hypothesis REINSTATES the round.
4. **One design round adjudicates a fork.** When two candidates are live,
   present BOTH grounded in recons (what each requires, what each breaks) —
   never present the preferred one alone.
5. **New-kind activation at sketch time.** For every sketched headline
   advertised as introducing support for a new constructor/kind, run the
   activation test BEFORE any code exists: one canonical positive value of
   the new kind, every premise and conjunct evaluated on both sides, the
   activation matrix for conjunction headlines (find-and-prove
   `references/vacuity.md` A8). A sketch can carry the vacuity — reviewers
   checking sketch-FIDELITY then propagate it (W3.6a: the design authority's
   own sketch shipped a join-arm conjunction where both new-kind sides were
   false; three fidelity reviews passed it). No positively-inhabited
   new-kind witness ⇒ the sketched statement is a transport corollary, not
   the new-kind headline.
